Connect your AI

The MCP server is public, read-only and needs no key. Pick your client and paste. All clients and the exact formats are in the docs.

claude mcp add --transport http papertrade-yield https://papertrade-yield.pages.dev/mcp

Settings, Connectors, Add custom connector, then paste the URL. For the stdio bridge, use this in claude_desktop_config.json.

https://papertrade-yield.pages.dev/mcp
{
  "mcpServers": {
    "papertrade-yield": {
      "command": "npx",
      "args": ["-y", "mcp-remote", "https://papertrade-yield.pages.dev/mcp"]
    }
  }
}
codex mcp add papertrade-yield --url https://papertrade-yield.pages.dev/mcp

Enable Developer mode in ChatGPT settings, create a connector, paste this URL and choose no authentication.

https://papertrade-yield.pages.dev/mcp
gemini mcp add --transport http papertrade-yield https://papertrade-yield.pages.dev/mcp

Add to .cursor/mcp.json.

{
  "mcpServers": {
    "papertrade-yield": { "url": "https://papertrade-yield.pages.dev/mcp" }
  }
}

Add to .vscode/mcp.json.

  }

Quickstart

No account, key or install. Read the data, call the tools, then connect an agent.

Read the yield

curl -s https://papertrade-yield.pages.dev/api/staking \
  | jq '.yield.windows[] | {label, usdPer1MPaperPerDay}'

Call an MCP tool

curl -s https://papertrade-yield.pages.dev/mcp \
  -H 'content-type: application/json' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/call","params":{"name":"get_apr","arguments":{}}}'

Self-hosting on Cloudflare Pages needs no database or secret. See the guide.
